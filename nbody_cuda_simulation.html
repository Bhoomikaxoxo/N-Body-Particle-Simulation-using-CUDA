What to notice

The 2D visualization calculates softened gravity from every other particle on each frame. The CUDA version assigns one thread to each target particle and advances all particle positions and velocities.

The five host-side steps

01 · ALLOCATE

Host + device memory

malloc arrays on the CPU; cudaMalloc matching arrays on the GPU.

02 · COPY IN

CPU to GPU

cudaMemcpy(..., cudaMemcpyHostToDevice) copies the initial positions and velocities.

03 · LAUNCH

Run the kernel

Launch with <<<grid, block>>>; threads calculate forces and update particles.

04 · COPY OUT

GPU to CPU

cudaMemcpy(..., cudaMemcpyDeviceToHost) returns the updated state.

05 · FREE

Release memory

Call free for CPU arrays and cudaFree for GPU arrays.

Core takeaways for this case study

01 · PARALLELISM

Identify independent work

The force on each target particle can be calculated independently. Assign a CUDA thread to each target; each thread loops over all source particles.

02 · MEMORY HIERARCHY

Reuse shared data

Threads in a block load source positions into shared-memory tiles and reuse them, reducing repeated global-memory reads.

03 · BOUNDARIES

Check the index

The final block may contain extra threads. Check if (i < N) before reading or writing particle data.

Kernel pattern

int i = blockIdx.x * blockDim.x + threadIdx.x;
if (i < N) {

Complete CUDA program

The one-timestep program follows the five steps and updates velocity and position. It also checks CUDA errors and uses shared-memory tiles.

Open nbody_cuda.cu

Boundary threads still participate in block-wide synchronization, while only valid particle indices read and write particle data.

Complexity: every target visits N − 1 other particles, so each timestep has N × (N − 1) ordered interactions and O(N²) work. At N = 100,000, that is about 10 billion interactions per timestep.

Controls: pause/resume, reset, particle count, and playback speed. This 2D visualization uses softened gravity and a simple time step. The CUDA source implements one timestep of the same all-pairs calculation.
